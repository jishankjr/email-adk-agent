# Email ADK Agent

An AI-powered Email Agent built using Google's Agent Development Kit (ADK).

## Features

- Send emails using Gmail
- AI-powered email generation
- Google ADK integration
- Environment variable support

## Project Structure

```
email-adk-agent/
│
├── email_agent/
│   ├── __init__.py
│   └── agent.py
├── .env
├── credentials.json
├── .gitignore
└── requirements.txt
```

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
adk web
```
